# Cosegan community service

Bugs that [Cosegan](https://cosegan.com) found in open-source software, as community service: the projects are open source and free to use, and this work is done for them without charge. Each finding is written as a report for the project's maintainers: what was run, what was seen, and where in the code it comes from.
